# 장기 배움터

초보자가 컴퓨터와 장기를 두면서 매 차례 최대 5개의 추천 수와 이유를 비교할 수 있는 로컬 학습 프로그램입니다.

## 실행

Python 3.11 이상에서 별도 패키지 설치 없이 실행합니다.

```bash
python -m app.server
```

브라우저에서 `http://127.0.0.1:8000`을 여세요.

## Vercel 배포

`public/`의 정적 학습 화면과 `api/`의 Python API를 Vercel에 배포하도록 구성되어 있습니다. 서버리스 환경에서는 각 브라우저에 세션 쿠키를 발급해 대국 상태를 분리합니다. 서버리스 인스턴스가 재시작되면 진행 중인 대국은 새로 시작됩니다.

## 기능

- 초/한 진영 선택 및 컴퓨터 선공 지원
- 1~5단계 컴퓨터 난이도
  - 1: 다양한 합법 수 경험
  - 2: 기물 이득 우선
  - 3: 상대의 다음 수 고려
  - 4: 두 수 읽기
  - 5: 세 수 읽기
- 내 차례마다 합법 수 중 최대 5개를 추천하고, 기물 포획·중앙 점유·전개 관점의 이유 표시
- 클릭으로 직접 수를 두거나 추천 수를 클릭해 진행
- 선택한 말의 합법 이동 경로를 반투명선으로 표시
- 장군 상태에서는 궁을 지키는 수만 허용하고, 둘 수 있는 합법 수가 없을 때만 한 수 쉼 허용

## 적용 규칙

친선대국 모드로 동작합니다. 대한장기협회 기준에 따라 궁·사·차·포·마·상·졸/병의 행마, 궁성 대각선, 포의 뛰기·포 상호 통과/취득 금지, 마·상의 멱, 졸/병의 전진 및 궁성 대각선, 자장 방지를 적용합니다.

- [기물 행마법](http://www.kja.or.kr/business/business3.php)
- [대국 규칙](http://www.kja.or.kr/business/business5.php)
- [대국 규정](http://www.kja.or.kr/business/business6.php)
- [장기 용어](http://www.kja.or.kr/business/business7.php)

학습 목적의 친선대국에서는 협회 규정의 설명에 따라 빅장과 반복수를 허용합니다. 대회 시간, 계시, 심판 판정, 실격 및 리그 승점은 대국 운영 규정이므로 이 로컬 단일 대국 프로그램의 자동 판정 범위에는 포함하지 않습니다.
